1

¿Qué es Git?

Git es una herramienta de control de versiones.
Te permite guardar el historial de tu proyecto.

Ejemplo:

¿Por qué usamos Git?

Nuestro jefe puede pedirnos que cambiemos el color de una parte de una página web y, después de ver el resultado, decirnos que el color anterior era mejor.

Si utilizamos Git, podemos volver a la versión anterior sin tener que recordar ni rehacer manualmente todos los cambios.

2

Git vs GitHub

Git: sirve para guardar los cambios que hacemos en nuestro proyecto en local y poder volver a una versión anterior si lo necesitamos.

GitHub: sirve para guardar nuestro proyecto en Internet. Así podemos tener una copia en línea, compartirla y trabajar con otras personas.

Git guarda los cambios en nuestra computadora y GitHub nos permite subir ese trabajo a Internet.

Para comprobar tu nombre escribe:

¿Cómo crear nuestro primer repositorio con Git?

Debes seguir los siguientes pasos:

Paso 1

Creamos una carpeta.

Paso 2

Entramos a la carpeta.

Paso 3

En un espacio vacío, presionamos
clic derecho.

Paso 4

Presionamos:
Open Git Bash here.

Paso 5

Activamos para ver "Archivos Ocultos":


Dentro de la carpeta

En la parte superior presionamos Vista.

Entramos a Agrupación Mostrar.

Marcamos "Elementos ocultos".

Esto permitirá ver la carpeta que genera GIT
Paso 6

Inicializar repositorio GIT


En la terminal escribimos: 
git init

El comando git init permite iniciar Git dentro de la carpeta de nuestro proyecto.

En ese momento nos mostrará un mensaje indicando que el repositorio fue creado correctamente.

Dentro de nuestra carpeta aparecerá una nueva carpeta oculta llamada: .git
Paso 7

Crear un repositorio Git con una rama que tenga un nombre diferente a master


Al usar git init, Git puede crear la rama inicial con el nombre master.

Si queremos colocar otro nombre, escribimos: 
git init --initial-branch="nombre"

Ejemplo: 
git init --initial-branch="principal"
Paso 8

Modificar el nombre del repositorio Git


Si ya creamos el repositorio y queremos cambiar el nombre de la rama actual, escribimos: 
git branch -m "nuevo-nombre"

Ejemplo: 
git branch -m "main"
7

¿Qué es el archivo .gitignore?

El archivo .gitignore sirve para indicarle a Git qué archivos o carpetas no queremos guardar.

Para crear el archivo sigue estos pasos:

Paso 1

En Git Bash dentro de la carpeta de nuestro proyecto y escribimos:

touch .gitignore

Crea un archivo llamado .gitignore dentro de nuestro proyecto.
Paso 2

Abrimos el archivo .gitignore

Dentro del archivo podemos indicar que archivo o carpeta queremos ignorar de la siguiente manera:
  • Archivo: Colocamos el nombre completo del archivo. contraseña.txt
  • Carpeta: Colocamos el nombre de la carpeta seguido de /. privado/
  • Varios archivos: Colocamos cada archivo en una línea diferente.
    contraseña.txt
    datos.txt
    prueba.txt
  • Varios tipos de archivos: Utilizamos * para ignorar todos los archivos que tengan la misma extensión. *.log
  • Archivos y carpetas: Podemos combinar diferentes elementos.
    contraseña.txt
    privado/
    node_modules/
    *.log
Paso 3

Podemos generar un .gitignore automáticamente

Podemos utilizar una página que nos ayuda a generar el contenido del archivo .gitignore según la tecnología que utilizamos. 

https://www.toptal.com/developers/gitignore

Escribimos la tecnología que estamos utilizando, y presionamos Create.

La página generará el contenido que podemos copiar y pegar dentro de nuestro archivo .gitignore .

¿Qué es el archivo README.md?

El archivo README.md sirve para explicar de qué trata nuestro proyecto .

Podemos colocar información como el nombre del proyecto, una descripción, cómo utilizarlo y otros datos importantes.

Para crear y utilizar el archivo sigue estos pasos:

Paso 1

Creamos el archivo README.md

En Git Bash, dentro de la carpeta de nuestro proyecto, escribimos: 

touch README.md

Este comando crea un archivo llamado README.md dentro de nuestro proyecto.

Paso 2

Abrimos el archivo README.md

Dentro del archivo podemos escribir información sobre nuestro proyecto.

Nombre del proyecto: Indica su nombre.

Descripción: Explica de qué trata.

Uso: Cómo utilizar el proyecto.

Autor: Quién creó el proyecto.

Paso 3

Conocemos algunas formas de escribir dentro de README.md

El archivo README.md utiliza una forma sencilla de escribir llamada Markdown .

Título:
# Mi proyecto
Subtítulo:
## Descripción
Texto en negrita:
**Texto importante**
Lista:
- HTML
- CSS
- JavaScript
Paso 4

Podemos crear nuestro README.md con una página

También podemos utilizar una página que nos ayuda a crear nuestro archivo README.md de forma más sencilla. 

https://readme.so/

Ingresamos a la página y podemos ir agregando las secciones que necesitamos para nuestro README.

Unidad 1

¿Cómo instalar Git en Windows?

Para trabajar con repositorios en sistemas Windows, instalaremos el paquete oficial de Git for Windows, el cual incluye Git Bash, una terminal de comandos robusta y compatible con estándares Unix.

Paso 1

Descargar el instalador oficial

Dirígete al sitio web oficial y descarga la última versión estable del instalador para la arquitectura de tu equipo Windows (64-bit).

https://git-scm.com/download/win
Paso 2

Ejecutar el instalador con opciones recomendadas

Abre el archivo descargado. Puedes mantener las opciones predeterminadas recomendadas por el asistente (Next, Next...) asegurando que permita usar Git desde Git Bash.

Paso 3

Verificar instalación en Git Bash

Abre la aplicación Git Bash en tu PC con Windows y comprueba que esté lista para usar ejecutando el comando de verificación: 

git --version
Unidad 2

¿Cómo configurar tu identidad?

Una vez instalado Git en Windows, personaliza tu perfil global para que cada commit registre tu nombre y correo personal de manera oficial.

Paso 1

Configurar nombre de usuario

Escribe el siguiente comando en tu terminal Git Bash estableciendo tu nombre de usuario oficial:

git config --global user.name "Tu Nombre Completo"
Paso 2

Configurar correo electrónico

Vincula tu cuenta de correo electrónico asociada a GitHub o GitLab mediante el comando de configuración:

git config --global user.email "tu.correo@ejemplo.com"
Unidad 3

¿Cómo iniciar un repositorio?

Crea directorios de trabajo en tus unidades de disco de Windows (como `C:` o `D:`) y dota de control de versiones a tus proyectos usando la terminal.

Paso 1

Crear y acceder a la carpeta del proyecto

Abre Git Bash y crea una nueva carpeta para almacenar los archivos de tu aplicación web:

mkdir mi-proyecto-web
cd mi-proyecto-web
Paso 2

Inicializar el repositorio local

Activa el motor interno de Git ejecutando el comando de inicialización: 

git init
git status
Unidad 4

¿Cómo guardar tus cambios?

Consolida tus modificaciones registrándolas en el historial mediante la zona de preparación (staging area) y los commits descriptivos.

Paso 1

Preparar archivos con Git Add

Añade todos los archivos nuevos o editados al staging area para incluirlos en el próximo empaquetado:

git add .
Paso 2

Guardar con un mensaje descriptivo

Confirma el guardado permanente generando un commit con un mensaje claro:

git commit -m "feat: estructura inicial del proyecto en windows"
Unidad 5

¿Cómo subir a GitHub?

Conecta tu repositorio local con una plataforma en la nube como GitHub para respaldar y compartir tu código con otros desarrolladores mediante un repositorio remoto.

Paso 1

Vincular con el servidor remoto

Conecta tu repositorio local con la URL del origen remoto creado en GitHub:

git remote add origin https://github.com/usuario/mi-proyecto-web.git
Paso 2

Enviar avances con Push

Sube tu rama principal hacia GitHub ejecutando una instrucción push definitiva:

git push -u origin main
